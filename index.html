What the game is

One shared machine, several hidden plans.

Compiled turns a programming idea into a board game. The board is a loop of memory slots. The cards are small instructions. The CPU has four shared data registers, R0 through R3, and four status flags, Z, N, C, and V.

Your six-card hand and objective are private. The board and CPU are public. Stage one card, review it, then press Run to commit your move and refill your hand. You win when both conditions of your objective hold at the end of your own run.

01

Program the loop

Overwrite memory slots with cards like MOVE #3, R0, XCHG R2, R0, or BRA -2.

02

Run the CPU

Four-bit values read as signed -8 to +7 or unsigned 0 to 15. Arithmetic wraps; empty slots execute NOP and stop the run.

03

Keep your objective quiet

Meet two conditions at once. Objectives specify Signed or Unsigned, and objective sums use full mathematical totals without four-bit wrapping.

Turn flow

A turn is short. The consequences are not.

  1. Stage

    Swipe through six cards, three at a time. Choose a card and a memory slot in either order; occupied slots can be overwritten.

  2. Review

    The tray switches to Ready to Run. Use Change Card to revise your choice, or Run to commit it and draw back up to six.

  3. Advance

    Your Program Counter moves one slot before execution begins.

  4. Execute

    Register instructions end the run. BRA can chain up to five executed instructions before the turn stops.

  5. Check

    Only your objective is checked, after execution ends. Both conditions must be true together to win.

Know your operands

  • Signed immediate values: -5 to +5, excluding zero. Unsigned immediates: 1 to 15.
  • Binary operations can also read a source register instead of an immediate value.
  • XCHG is the current name for the exchange operation. REV reverses all four bits.
  • BRA jumps -3 to +3 slots, excluding zero. Branch chains stop at the five-instruction limit.
  • NOP stops a run without changing registers or flags. It can be dealt as a card as well as encountered on empty slots.

Read the bits your way

Four formats. One CPU.

Switch between S-DEC, U-DEC, HEX, and BIN. Tap a data register to inspect the same bits in both decimal interpretations, hexadecimal, and binary. The register converter also lets you explore R0–R3 and the status flags.

Changing the display never changes execution or your objective. Signed arithmetic wraps from +7 to -8; unsigned arithmetic wraps from 15 to 0. Both keep the low four bits.

Z/N

Read the result

Z means the result is zero. N mirrors the top bit: negative when read as signed, or 8–15 when read as unsigned.

C/V

Carry and overflow differ

C tracks unsigned carry or borrow; shifts and rotations copy the outgoing bit into C. V reports signed arithmetic overflow. Unsigned arithmetic clears V.

+1

Try the boundary

On the bits for 7, ADD #1, R0 sets V=1 and C=0. ADDU #1, R0 produces the same bits with both flags clear.
