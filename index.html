How to Play Compiled

A turn in Compiled represents one execution clock cycle on the shared 4-bit virtual processor.

  1. 1. Receive Mission & Hand

    Draw your classified private secret objective and starting instruction hand. Your objective defines a target register state (e.g. R0 = -R1 and R0 >= +3 or R1 + R3 = -4 and R1 < 0). Objectives stay secret from other players.

  2. 2. Place One Card

    Choose one instruction card from your hand and program it onto any slot around the circular memory loop (12, 16, or 20 slots). Overwrite existing instructions to build chained execution loops or disrupt rival plans.

  3. 3. Draw Replacement

    Immediately draw a replacement instruction card from the deck to maintain your tactical hand before initiating program execution.

  4. 4. Advance & Run CPU

    Your Program Counter (PC) advances by one memory slot before execution. Register commands run and immediately halt the turn; BRA branches relative to the current slot and can chain executions (capped at 5 instructions max). Empty slots resolve as NOP and halt the turn.

  5. 5. Check Secret Objective

    Secret objectives are evaluated only after the active player's execution phase finishes. You win only when your own turn finishes with your secret objective fully satisfied!

// INSTRUCTION SET ARCHITECTURE (ISA)

SIGNED 4-BIT VIRTUAL CPU

All arithmetic operations modify shared registers R0–R3 and update status flags Z (Zero), N (Negative), C (Carry), and V (Overflow) with clean signed two's complement wrapping (-8 through +7). Full strategy guides for each opcode are available in the in-app Card Dictionary.

Category Opcode Syntax Example Operation & In-Game Effect
Value / Arithmetic MOVE MOVE #5, R0 Loads an immediate signed integer directly into the target register.
ADD ADD #2, R1 Adds immediate value with 4-bit two's complement wrap (-8..+7). Updates Z, N, C, V.
SUB SUB #3, R2 Subtracts value from target register with wrapping arithmetic. Updates flags.
MUL MUL #2, R0 Multiplies target register by signed immediate with 4-bit wrapping. Updates flags.
Bitwise Logic AND AND #3, R0 Bitwise logical AND with mask. Clears bits not set in immediate.
OR OR #5, R2 Bitwise logical OR with mask. Sets specific bits in target register.
XOR XOR #-2, R0 Bitwise exclusive OR. Inverts selected bits in target register.
Unary Ops INC INC R0 Increments register by 1 (e.g. +7 wraps to -8). Updates flags.
DEC DEC R3 Decrements register by 1 (e.g. -8 wraps to +7). Updates flags.
NEG NEG R2 Two's complement arithmetic negation (reverses sign: +5 becomes -5).
CLR CLR R1 Clears register value to 0. Sets Zero flag (Z=1).
NOT NOT R0 Bitwise one's complement inversion (flips all 4 bits).
Shifts & Rotates LSL LSL R1 Logical shift left by 1 bit, shifting 0 into the least significant bit.
LSR LSR R2 Logical shift right by 1 bit, shifting 0 into the most significant bit.
ROL ROL R1 Rotate left: bits shifted out of MSB re-enter at LSB.
ROR ROR R3 Rotate right: bits shifted out of LSB re-enter at MSB.
Control / System SWAP SWAP R1, R2 Exchanges contents between two designated registers simultaneously.
BRA BRA +02 / BRA -03 Relative branch jump: leaps Program Counter forward or backward up to 5 chained instructions.
NOP NOP No operation. Represents an empty board slot; immediately stops execution for the turn.

About CompiledAndroid

CompiledAndroid is an Expo / React Native mobile application bringing the tactical depth of Compiled to phones and tablets. Built as a tribute to vintage computer hardware and deduction board games, it challenges players to manipulate a shared signed 4-bit CPU while concealing their private hands and objectives.

Every turn is an architectural dance: place an assembly card onto the circular memory loop, advance your Program Counter, run opcodes that alter the global registers, and race to fulfill your private mission. With local Pass & Play turn handoffs, an adaptive AI opponent that never cheats on hidden info, an in-app Card Dictionary, and an interactive 11-step academy, CompiledAndroid makes low-level computing concepts thrilling and accessible.

Offline-first, ad-free, and engineered for tactile strategy: prove your mastery over the shared processor.
