How to Play Compiled

A turn in Compiled represents one execution clock cycle on the shared processor.

  1. Receive Mission

    Draw your classified secret objective and 5 instruction cards. Your objective defines a specific register condition (e.g. R1 = -3 or R0 + R1 = 5) needed to claim victory.

  2. Stage Code

    Choose one instruction card from your hand and program it onto any of the 20 memory slots on the board. You can overwrite existing code to disrupt rival players' planned jumps.

  3. Step the CPU

    Advance your Program Counter by one tile. Execute the instruction present on that memory slot. Empty slots resolve as NOP (No Operation).

  4. Mutate Registers

    Opcodes modify shared registers R0 through R3. All register values wrap cleanly in signed two's complement between -8 and +7.

  5. Verify Objective

    Branch commands (BRA) can trigger up to 5 cascaded executions! If the registers satisfy your secret objective at the conclusion of your turn, you win immediately.

Opcode Syntax Example Operation & Tabletop Effect
MOVE MOVE #5, R0 Loads an immediate signed integer value directly into the target register.
ADD ADD #2, R1 Adds immediate value to target register with two's complement wrapping (-8..+7).
SUB SUB #3, R2 Subtracts value from target register with wrapping arithmetic.
INC / DEC INC R0 / DEC R3 Increments or decrements register value by 1.
NEG NEG R2 Negates the sign of the register value (reverses positive/negative).
CLR CLR R1 Clears register contents back to 0.
SWAP SWAP R1, R2 Exchanges values between two designated registers simultaneously.
BRA BRA +02 / BRA -03 Branch instruction: relative jump that leaps your Program Counter forward or backward up to 5 steps.

About Compiled

Compiled was born from a passion for early computing architecture—specifically the legendary Motorola 68000 microprocessor—and the tense psychological bluffing of classic deduction tabletop games.

What started as an experimental browser-based prototype has evolved into a dedicated Android mobile game. By moving from a browser toy to a native mobile experience, Compiled provides responsive touch-driven interaction, robust offline AI play, clean pass-and-play party sessions, and an environment free of pop-up ads or online bloat.

The mission remains simple: demonstrate that assembly language principles—registers, memory addresses, and program counters—are not dry academic theory, but the blueprint for one of the most thrilling tabletop games you will ever play.
