What the game is

One shared machine, several hidden plans.

Compiled turns a programming idea into a board game. The board is a loop of memory slots. The cards are small instructions. The CPU has four shared data registers, R0 through R3, and four status flags, Z, N, C, and V.

Your hand and objective are private. The board and CPU are public. On your turn, you place one card, draw back up, then run from your Program Counter. If the registers match your objective when execution stops, you win.

01

Program the loop

Overwrite memory slots with cards like MOVE #3, R0, SWAP R2, R0, or BRA -2.

02

Run the CPU

Registers wrap from -8 to +7. Empty slots are NOP and stop execution.

03

Keep your objective quiet

Everyone can see the same board state, but only you know exactly which register pattern you need.

Turn flow

A turn is short. The consequences are not.

  1. Place

    Choose one card from your hand and put it on any memory slot. Existing instructions can be overwritten.

  2. Draw

    A replacement instruction goes into your hand, keeping future plans flexible.

  3. Advance

    Your Program Counter moves one slot before execution begins.

  4. Execute

    Register instructions end the run. BRA can chain up to five executed instructions before the turn stops.

  5. Check

    Your private objective is checked only after your own execution phase ends.

Modes in the app

Built for solo puzzle fights and same-device play.

Singleplayer

Play against one to three CPU rivals. Easy plays loosely, Normal scores objective progress, and Hard adds a small lookahead.

Pass and Play

Set up two to four players on one device. Mix humans and CPU rivals, then hand off between turns while private cards and objectives are hidden.

Tutorial

An 11-step guided match teaches the CPU, memory board, instruction cards, branching, and objective timing.

Card Dictionary

Browse every instruction in the app with syntax, examples, 4-bit math behavior, and tactical notes.

Settings

Switch number display between decimal, hex, and binary, choose animation speed, and open the register converter.

Instruction set

Small cards, exact effects.

Cards are structured instructions, so you are choosing specific changes rather than vague actions. Immediate values range from -5 to +5, branches move -3 to +3, and each player holds five cards.

MOVE ADD SUB AND OR XOR MUL INC DEC NEG CLR NOT LSL LSR ROL ROR SWAP BRA NOP
